# 有赞烘焙 · 品牌概念官网

以五段烘焙影像为主线的 React + Vite 滚动叙事网站。包含巨型反色字体、逐字滚动文案、错速摄影、横向产品画廊、产品详情弹窗和页尾曲线动效。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4173
```

访问 http://127.0.0.1:4173/ 。

```sh
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
npm run test:sites
```

静态构建输出为 `dist/client`。仓库保留了可选的 Sites worker、构建脚本及测试，不包含支付、订单后台或部署凭据。

## 项目结构

- `src/`：页面、样式及滚动视频引擎。
- `public/assets/`：运行所需的全部视频和图片。
- `media/youzan-bakery-full-720p.mp4`：五段网页视频无损顺序拼接版，约36.96秒、1280×720、24fps、无音轨，供超清处理。
- `asset-brief/`：素材说明与参考资料。
- `qa/`、`design-qa.md`：迭代过程中的截图及验证记录，部分记录对应早期版本。
- `THIRD_PARTY_LICENSES/`：第三方授权说明。

## 当前效果与素材

首屏使用用户提供的2560×1440保真增强图片 `opening-hd.webp`，进入镜头后直接交接视频，没有叠化；最后一个镜头结束时展示 `final-hd.webp`，回滚时恢复视频。高清图片和视频共用画面尺寸与变换。

五段视频为 `shot-1.mp4` 至 `shot-5.mp4`，原生1280×720、24fps。第二镜使用重生成版本的前4.791667秒；第五镜在网页内有时间映射以加速通过中段。完整拼接视频不包含网页文案、滚动变速或网页片段间的短暂交接。

静态摄影包括擀面团、可颂剖面、黄油、巧克力酥、工作室与高清产品图。移动端使用纵向作品布局，支持系统减少动态效果偏好。

## 设计与授权

设计研究参考了 Lune 官网的排版与工艺叙事；没有复用其品牌、图片或代码。本项目为“有赞烘焙”概念演示，不代表官方上线网站。

`src/scroll-world.js` 改编自 oso95/scroll-world 的 MIT 参考引擎，授权文本位于 `THIRD_PARTY_LICENSES/`。未修改全局 skill。

## 验证与限制

已进行桌面和手机尺寸的本地浏览器验证，包括首尾高清静帧、影片文案、导航、产品详情和页尾图形；构建通过。视频超清版尚未接入，真实 iPhone Safari 的解码性能仍需实机验证。

## 连续叙事动效更新

影片结束后的高清尾帧保持在同一图层，随滚动收缩为产品展示；原味产品卡片与详情使用相同的尾帧素材。工艺摄影从叠放展开至两侧，中央显露文案。产品详情使用图片位置连续过渡，支持关闭回位、Escape 和原焦点恢复；浏览器不支持 Popover 或用户选择减少动态效果时使用普通弹窗。

三段影片文案分别使用字距舒展、错速横移、延迟显影。缎带从工艺区的6根线、作品区的12根线延伸到页尾22根线。指针视差仅对支持悬停且未开启减少动态效果的设备启用。
